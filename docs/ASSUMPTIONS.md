# Что реально, что упрощено

Честный список. Всё из первой колонки можно проверить руками — команды в
[AGENT-BRIEF.md](AGENT-BRIEF.md).

## Реально

- **Все цены, рейсы и отели** — живые ответы Tutu MCP в момент поиска; в
  коде нет ни одной захардкоженной цены. Кэш только ускоряет повторы
  (TTL настраивается, на демо — сутки).
- **Checkout** — живая ре-валидация каждого плеча и отеля с diff цен;
  ссылки на оплату — настоящие `create_checkout_link` Туту.
- **Копилот** — настоящие вызовы LLM (OpenRouter): черновики, осмысление
  результатов, постановка пересадки. Журнал шагов в чате — реальные события
  поиска, не заготовки.
- **Голосовой ввод** — настоящее распознавание (OpenRouter ASR).
- **Схема вагона** — геометрия мест из `get_rail_seatmap`, места выбираются.
- **Пересадки** — живой перебор хабов двумя поисками на кандидата;
  LLM только предлагает кандидатов, проверяет всегда MCP.
- **Курсы валют** — ЦБ РФ; при недоступном cbr.ru честный фолбэк на
  закоммиченный снапшот (дата снапшота видна в коде).

## Упрощено или ограничено

- **Кэш в памяти процесса.** Одна реплика — жёсткое требование деплоя;
  рестарт = холодный кэш (лечится прогревом `npm run warm`).
- **Персистентность** — план в URL-фрагменте + localStorage со снимком на
  24 часа (цены протухают). Аккаунтов и БД нет.
- **Раунды осмысления копилота** капнуты двумя на черновик — защита от
  зацикливания ReAct-петли, а не принципиальное ограничение.
- **Хабы пересадок** — статический список (Москва, Стамбул, Дубай, СПб и
  др.) плюс LLM-подсказка под конкретную пару; при сбое LLM — только
  статический список.
- **Дети в поисках** — маппинг консервативный: подростки 12+ считаются
  взрослыми, у ж/д передаётся только количество пассажиров (ограничение
  инструментов MCP, см. MCP-FEEDBACK п. 5).
- **Стыковки считаются по локальным временам из офферов** — при
  экзотических сменах часовых поясов внутри плеча оценка «успеваем ли»
  может отличаться на часы; ремонт закладывает минимум 90 минут.
- **Ссылки на оплату не проверяются автоматически** — `mtp-deeplink`
  отвечает 401 вне браузера (MCP-FEEDBACK п. 6); мы проверяем создание
  ссылки, а не её открытие.
- **Демо-легенда** — реальный маршрут, проверенный против живого MCP, но
  прогретый заранее: холодный прогон занимает ~48 секунд, на сцене это
  время не показывают.
- **Офлайн-режим карты** — схематичный контур; уличной детализации без
  сети и ключа MapTiler нет (это фолбэк, а не обман: тайлы подписаны
  атрибуцией, схема — «схематичная карта»).
