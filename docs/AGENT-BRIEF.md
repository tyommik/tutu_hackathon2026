# Тропа — справка для жюри

Самодостаточный документ: по нему проект можно оценить, не читая репозиторий.
Каждое утверждение снабжено способом проверки. Стенд — https://tutu.shibaev.info
(выкладывается `deploy/push.sh`); локальный запуск — две команды, ключи не нужны.

## Что это

**Тропа** — конструктор мультигородских путешествий на данных
[Tutu MCP](https://mcp.tutu.ru/mcp). Поездка собирается по кирпичикам на карте
(или ИИ-копилотом по одной фразе), и после каждого изменения плана система
сама находит реальные покупаемые билеты и отели. В конце «Checkout всего
маршрута» пере-проверяет каждое плечо живьём и отдаёт свежие ссылки на оплату
с diff цен.

**У Wanderlog маршрут — картинка. У нас — корзина.**

Ключевой инсайт ниши: `search_multitransport` Туту не строит составные
маршруты — он параллельно опрашивает виды транспорта на одну пару городов.
Цепочку «Старый Оскол → Москва → Стамбул → Порту» приходится собирать по
плечам самому — ровно эту работу Тропа и автоматизирует.

## Что смотреть (5 минут)

1. Открыть стенд → карточка **«В Бразилию»** на стартовом экране. Копилот
   собирает черновик из 6 плеч, автопоиск наполняет его живыми ценами,
   статусы шагов идут в чат, затем копилот сам осмысляет результаты
   («всё нашлось, бюджет ~990 тыс. на троих»).
2. Написать копилоту «Из Воронежа в Бостон» — прямых рейсов нет, система
   подберёт пересадку через хабы, а копилот **сам поставит её в план**
   (инструмент `apply_transfer`) и подведёт итог. Это ReAct-петля:
   черновик → поиск → автоотчёт → действие → пере-осмысление.
3. Кликнуть отель в плане — карта плавно летит к городу, отели ложатся
   пинами с ценами на уличные тайлы; клик по пину — карточка, «Ок» выбирает
   и возвращает вид.
4. **«Checkout маршрута»** — живая ре-валидация каждой позиции с diff цен и
   ссылками на оплату Туту.
5. Кнопка «Загрузить демо-легенду» (пустой план) — маршрут
   Старый Оскол → Стамбул → Порту → Лиссабон → Мадрид → Барселона → обратно,
   проверенный против живого MCP.

## Принцип: LLM не влияет на корректность

- Черновик копилота применяется **тем же код-путём, что ручная сборка**:
  plain-список городов и дат, цены находит поиск.
- Цены и рейсы в ответах модели берутся только из автоотчёта поиска
  (`src/lib/searchReport.ts`); системный промпт прямо запрещает выдумывать.
- Действие `apply_transfer` применяет **уже найденный системой** вариант
  пересадки тем же кодом, что кнопка в интерфейсе; галлюцинация в аргументах
  упирается в поиск плеча по названиям городов и заканчивается статусом
  «пересадка ещё не подобрана», а не порчей плана.
- Раундов осмысления — не больше двух на черновик: петля не зацикливается.
- Без `OPENROUTER_API_KEY` копилот честно отключается, ручной режим полный.

Исключение одно и осознанное: LLM может **предлагать** хабы для пересадок
(`src/lib/hubSuggest.ts`) — каждый кандидат всё равно проверяется живыми
поисками MCP, цена галлюцинации — два лишних запроса, не неверный ответ.

## Что под капотом (детали — в SYSTEM-MAP.md)

- **Авторемонт стыковок** (`src/lib/repair.ts`): автопоиск выбирает офферы
  плеч независимо, «дешёвый» рейс мог улетать до приезда предыдущего —
  ремонт перевыбирает выполнимый оффер или мягко сдвигает дату (кап 2).
- **Оптимизатор** (`/api/optimize`): детерминированный 2-opt перебор
  перестановок городов и сдвигов старта, скоринг цена + время; LLM не участвует.
- **Карта**: веб-Меркатор, тайлы MapTiler с переключалкой на офлайн-схему
  (контур Natural Earth запечён в код), подписи держат экранный размер при
  зуме, цены плеч не ложатся на линии.
- **Журнал агента**: каждый реальный шаг (поиск плеча, находка, пересадка,
  черновик) — статус в чате, история сворачивается экспандером
  «Как я искал · N шагов»; заготовленных фраз со смыслом «делаю вид, что
  работаю» больше нет.
- **Голос**: стартовый экран и чат диктуются (OpenRouter ASR), общий хук.
- **Свои траты**: такси/визы в любой валюте по курсу ЦБ, зафиксированному
  на момент добавления; при недоступном cbr.ru — снапшот курсов рядом с кодом.

## Как проверить утверждения

```bash
npm install && npm run dev          # http://localhost:3000, ключи не нужны
npx vitest run                      # 715 тестов чистой логики (lib/*.test.ts)
npx tsc --noEmit                    # строгие типы

# живой поиск через наш API (MCP Туту без авторизации):
curl -X POST localhost:3000/api/search -H 'Content-Type: application/json' \
  -d '{"kind":"leg","origin":"Порту","destination":"Лиссабон","date":"2026-09-15"}'
```

Копилот и голос требуют `OPENROUTER_API_KEY` в `.env.local`; тайлы —
`NEXT_PUBLIC_TILES_URL` (MapTiler). Без обоих ключей всё остальное работает.
